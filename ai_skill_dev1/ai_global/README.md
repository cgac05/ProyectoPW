## 🚀 Cómo Usar

### Para un Nuevo Proyecto

1. **Copiar estructura global** a `projects/<categoria>/<proyecto>/`
2. **Revisar agentes** para entender roles en `agents/README.md`
3. **Personalizar skills** del proyecto en `projects/<categoria>/<proyecto>/ai_work_flow/development/workflow_agents.yaml`
4. **Generar artefactos** usando templates de `templates/`
